# Contributing — bing-glava-suite

bing-glava-suite is a solo hobby project. There is no formal contribution
process and pull requests are not accepted at this time.

---

## Reporting bugs

Use the [GitHub Issues](https://github.com/Krzysztofci/bing-glava-suite/issues)
bug report template. Include:

- Linux distribution and version
- bing-glava-suite version or commit hash
- Steps to reproduce
- Terminal output / logs if available

## Suggesting features

Open an issue using the feature request template. No guarantees on
implementation — the roadmap is driven by personal use.

## Questions

Use the question issue template.
