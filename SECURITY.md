# Security Policy — bing-glava-suite

## Supported versions

Only the <img src="https://img.shields.io/github/v/release/Krzysztofci/bing-glava-suite?color=F0833a&label=Latest%20Release&style=flat" align="center"> on `main` receives fixes.

## Reporting a vulnerability

Do not open a public GitHub Issue for security vulnerabilities.

Report privately via GitHub:
**Security → Report a vulnerability** (in the repo's Security tab)

Or email directly: see the GitHub profile for contact details.

Expect a response within 7 days.
