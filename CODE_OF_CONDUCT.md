# Code of Conduct — bing-glava-suite

## The short version

Be respectful. Focus on the project.

## Expected behaviour

- Communicate constructively and politely
- Critique ideas, not people
- Accept feedback gracefully
- Stay on topic — this is a technical project

## Unacceptable behaviour

- Personal attacks or insults
- Harassment of any kind
- Spam or off-topic noise

## Reporting

Report issues via GitHub Issues or private vulnerability reporting (for
security matters). Maintainer reserves the right to close or ignore
issues that violate these guidelines.
